ONHUNDRED LOGO KIT

All letters are converted to shapes (Archivo, weight 780, width 80). No fonts needed.

svg/
  onhundred-wordmark.svg        Wordmark, transparent. For dark backgrounds only.
  onhundred-wordmark-dark.svg   Wordmark on Darkroom Black.
  on100.svg                     Square ON/100, transparent. For dark backgrounds only.
  on100-dark.svg                Square ON/100 on Darkroom Black (avatars, app icons).
  favicon.svg                   The lit O alone, for browser tabs.
  onhundred-social-card.svg     1200x630 link preview card.

png/
  Same logos at fixed sizes: wordmark 1200 and 2400 wide, square 180 / 400 / 512 / 1024,
  favicon 16 / 32 / 48 / 192, social card 1200x630.

favicon.ico                     16, 32 and 48 px in one file.

Colors
  Darkroom Black  #0A0A09   background
  Bone Paper      #E8E8E2   letters, dashed edges (60%)
  Live-Wire Green #C6F432   the O
  Dormant Grey    #7A7E74   the N fill

Size rules
  Square ON/100: use at 64 px and up. Below that, use the favicon.
  The transparent files have light letters; they disappear on white.
